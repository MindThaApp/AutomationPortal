# Voice

How Automation Portal talks to people. One calm person, plain words, no fuss.

1. Say what happened in the person's own words, with the shortcut's name in quotes and a real number.
   `"Tidy Downloads" moved 14 files.`
2. Say what is safe. "Nothing was overwritten." "Your files were not changed."
3. Offer one next step as a button with a verb on it: "Choose another folder", "Try again", "Open Settings".
4. Never use "Oops", "Successfully", "Error:", "Invalid", codes before words, or exclamation marks.

## Also

- System text (exception messages, error codes) never leads. Say a plain sentence first and keep the technical
  detail behind "See details", in Run history or in the log.
- Empty states have three parts: what this is, why it is empty, one button.
- Buttons are verbs. A button that destroys something names it: "Delete shortcut", never "OK".
- Tooltips carry the key when the command has one: "Run (Enter)", "Edit (Ctrl+E)", "Rename (F2)".
- No praise, no nagging, no made-up numbers. Say what was done, then stop talking.
