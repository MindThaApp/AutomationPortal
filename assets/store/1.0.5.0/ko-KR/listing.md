# 한 줄 소개

바로 가기는 한 번만 만들고, 어디서든 실행하고, 반복 작업은 자동화에 맡기세요.

# 설명

Automation Portal은 Windows 11에서 일상 작업을 자동화하는 트레이 앱입니다. 자주 반복하는 일을 간단한 바로 가기로 만들어 1초 만에 실행하세요. 매일 같은 클릭을 되풀이할 필요가 없습니다.

시각적 편집기에서 간단한 단계를 이어 바로 가기를 만들거나, 작업을 한 번 직접 해 보면 레코더가 단계를 대신 적어 줍니다. 갤러리의 준비된 바로 가기로 시작하거나, 원하는 일을 한 문장으로 설명해 초안을 받아 편집할 수도 있습니다.

실행은 빠르게. Win+Alt+Space를 누르고 이름이나 짧은 별칭을 입력한 뒤 Enter를 누르세요. 즐겨 쓰는 바로 가기는 고정해 두고 마우스 포인터 옆에 띄울 수 있습니다. 바로 가기마다 단축키를 지정하거나, 파일을 타일로 끌어다 놓아 그 파일에 대해 실행할 수 있습니다.

PC가 먼저 알아서 시작하게 하세요. 자동화는 정해진 시각, 충전기나 헤드폰 연결, 앱 실행, Wi-Fi 연결, 폴더 변경, 복사 동작 등을 계기로 바로 가기를 실행합니다. 요일, 배터리 잔량, 전체 화면 앱 같은 조건도 추가할 수 있습니다. 바로 실행할지, 먼저 물어볼지, 알림만 줄지 선택하세요.

통제권은 항상 사용자에게 있습니다. 자동화를 믿기 전에 임시 폴더의 샘플 파일로 먼저 테스트해 보세요. 너무 자주 실행되는 자동화는 자동으로 일시 중지되고, 스위치 하나로 모두 일시 중지할 수 있습니다. 모든 실행은 실행 기록에 단계별로 남으며, '파일 변경 취소'로 실행 중 만들어지거나 이동, 이름 변경, 교체된 파일을 되돌릴 수 있습니다.

어떤 앱에서든 ;sig 같은 짧은 코드를 입력하면 Automation Portal이 더 긴 텍스트로 바꿔 줍니다.

AI 단계는 선택 사항입니다. 내 PC의 Portal AI Host, Copilot+ PC의 Windows 온디바이스 AI, 또는 직접 만든 AI 계정으로 요약, 다시 쓰기, 번역, 이미지 설명을 할 수 있습니다. AI는 실행하는 바로 가기에 AI 단계가 있을 때만 사용됩니다.

Automation Portal은 x64 및 Arm64 Windows 11 PC용으로 Microsoft Store에서 받을 수 있습니다.

# 기능

- 시각적 편집기에서 간단한 단계로 바로 가기 만들기
- 작업을 한 문장으로 설명하고 편집 가능한 초안 받기 (AI 설정 필요)
- Quick Run: Win+Alt+Space를 누르고 이름이나 별칭 입력 후 Enter
- 어떤 앱에서든 선택한 텍스트에 Ctrl+Alt+R로 바로 가기 실행
- 트레이 아이콘과 마우스 포인터 옆에 고정된 바로 가기를 보여 주는 빠른 패널
- 바로 가기별 단축키, 또는 타일에 파일을 끌어다 놓아 실행
- 시간, 전원, 앱, 장치, Wi-Fi, 폴더, 클립보드 등으로 시작하는 자동화
- 요일, 시각, 전원 종류, 배터리 잔량, 전체 화면 앱 같은 조건
- 바로 실행, 실행/건너뛰기를 먼저 확인, 또는 알림만
- 임시 폴더의 샘플 파일로 자동화 테스트
- 너무 자주 실행되는 자동화는 자동 일시 중지, 스위치 하나로 전체 일시 중지
- 텍스트 조각: 짧은 코드를 입력하면 긴 텍스트로 변환
- 매크로 레코더: 작업을 한 번 하고 단계를 검토
- 추가하고 내 것으로 바꿀 수 있는 갤러리의 준비된 바로 가기
- 단계별 결과, 다시 실행, 실패한 단계에서 열기를 지원하는 실행 기록
- 만들어지거나 이동, 이름 변경, 교체된 파일을 되돌리는 파일 변경 취소
- 선택형 AI 단계: 요약, 다시 쓰기, 번역, 이미지 설명
- Portal AI Host, Copilot+ PC의 Windows AI 또는 내 AI 계정 사용
- 폴더, 고정, 아이콘과 색, 30일간 보관되는 최근 삭제 항목
- ap 명령줄과 공유 가능한 .autoportal 파일

# 무료 버전, 추가 기능, 무료 체험

Automation Portal은 무료로 다운로드해 사용할 수 있습니다. 무료 버전은 바로 가기를 5개까지 만들 수 있으며 갤러리, Quick Run, 텍스트 조각, 매크로 레코더, 실행 기록이 포함됩니다.

선택형 유료 추가 기능은 앱 안에서 Microsoft Store를 통해 구매합니다.
- Plus: 바로 가기 최대 25개.
- Pro: 바로 가기 개수 제한 없음, 새 자동화(일정 및 트리거) 만들기 가능. 새 자동화는 Pro에서만 만들 수 있습니다.

14일 Pro 무료 체험: 앱에서 '14일 무료 체험 시작'을 선택하세요. 카드는 필요 없습니다. 체험은 단추를 누를 때만 시작되며 Windows 사용자당 한 번만 가능합니다. 체험이 끝나도 만든 것은 삭제되지 않습니다. 기존 바로 가기와 자동화는 계속 실행되며 편집, 실행, 켜기와 끄기, 삭제도 할 수 있습니다. 추가 기능을 구매하기 전까지는 새 자동화와 요금제 한도를 넘는 새 바로 가기를 만들 수 없습니다.
