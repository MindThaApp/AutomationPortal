# タイトル

Automation Portal

# キャッチコピー

ショートカットは一度作るだけ。どこからでも実行でき、毎日の定型作業はオートメーションにおまかせ。

# 説明

Automation Portal は、Windows 11 での毎日の作業を自動化するタスクトレイ アプリです。繰り返す作業をシンプルなショートカットにまとめ、一瞬で実行。毎日同じクリックを繰り返す必要はもうありません。

ビジュアル エディターで簡単な手順をつなげてショートカットを作れます。作業を一度やってみせれば、レコーダーが手順を書き出します。ギャラリーの用意済みショートカットから始めることも、やりたいことを一文で書いて下書きを作り、あとから編集することもできます。

実行はすばやく。Win+Alt+Space を押し、名前か短いエイリアスを入力して Enter を押すだけ。お気に入りはピン留めして、マウス ポインターの位置に表示できます。ショートカットごとにホットキーを割り当てたり、ファイルをタイルにドラッグして、そのファイルに対して実行したりもできます。

PC に自分から動き出してもらいましょう。オートメーションは、決めた時刻、充電器やヘッドフォンの接続、アプリの起動、Wi-Fi への接続、フォルダーの変化、コピーの操作などをきっかけにショートカットを実行します。曜日、バッテリー残量、全画面アプリの有無などの条件も追加できます。すぐ実行する、先に確認する、通知だけする、のいずれかを選べます。

主導権はいつもあなたに。オートメーションは、信頼する前に一時フォルダー内のサンプル ファイルでテストできます。実行頻度が高すぎるオートメーションは自動で一時停止され、スイッチ 1 つですべてを一時停止できます。すべての実行は実行履歴に手順ごとに記録され、「ファイルの変更を元に戻す」で、実行によって作成、移動、名前変更、置換されたファイルを元に戻せます。

どのアプリでも ;sig のような短いコードを入力すると、Automation Portal が長いテキストに置き換えます。

AI ステップは任意です。要約、書き換え、翻訳、画像の説明を、お使いの PC 上の Portal AI Host、Copilot+ PC の Windows 搭載 AI、またはご自身の AI アカウントで行えます。AI が使われるのは、実行するショートカットに AI ステップがある場合だけです。

Automation Portal は、x64 および Arm64 の Windows 11 PC 向けに Microsoft Store で提供されています。

# 機能

- ビジュアル エディターで簡単な手順からショートカットを作成
- 作業を一文で説明すると編集可能な下書きを作成 (AI の設定が必要)
- Quick Run: Win+Alt+Space を押し、名前かエイリアスを入力して Enter
- どのアプリでも選択したテキストに Ctrl+Alt+R でショートカットを実行
- トレイ アイコンと、ピン留めしたショートカットをポインター位置に出すクイック パネル
- ショートカットごとのホットキー、またはタイルへのファイルのドラッグで実行
- 時刻、電源、アプリ、デバイス、Wi-Fi、フォルダー、クリップボードなどで開始するオートメーション
- 曜日、時刻、電源の種類、バッテリー残量、全画面アプリなどの条件
- すぐ実行、実行とスキップを先に確認、または通知のみを選択
- 一時フォルダーのサンプル ファイルでオートメーションをテスト
- 頻度が高すぎるオートメーションは自動停止、スイッチ 1 つで全体を一時停止
- スニペット: 短いコードを入力して長いテキストに展開
- マクロ レコーダー: 一度作業して手順を確認
- 追加してカスタマイズできるギャラリーの用意済みショートカット
- 手順ごとの結果、再実行、失敗した手順で開く機能を備えた実行履歴
- 作成、移動、名前変更、置換されたファイルを戻すファイル変更の取り消し
- 任意の AI ステップ: 要約、書き換え、翻訳、画像の説明
- Portal AI Host、Copilot+ PC の Windows AI、または自分の AI アカウントを利用
- フォルダー、ピン留め、アイコンと色、30 日間の最近削除した項目
- ap コマンド ライン、共有できる .autoportal ファイル

# 無料版、追加購入、無料体験

Automation Portal は無料でダウンロードしてお使いいただけます。無料版ではショートカットを 5 個まで作成でき、ギャラリー、Quick Run、スニペット、マクロ レコーダー、実行履歴を利用できます。

任意の有料アドオンは、アプリ内から Microsoft Store で購入できます。
- Plus: ショートカットを 25 個まで。
- Pro: ショートカットの数に制限がなく、新しいオートメーション (スケジュールとトリガー) を作成できます。新しいオートメーションを作成できるのは Pro だけです。

14 日間の Pro 無料体験: アプリ内の「14 日間の無料体験を開始」を選びます。カードは不要です。体験はボタンを押したときにだけ始まり、Windows ユーザーごとに 1 回限りです。体験が終わっても、作成したものは何も削除されません。既存のショートカットとオートメーションはそのまま動作し、編集、実行、オンとオフの切り替え、削除もできます。新しいオートメーションの作成と、プランの上限を超える新しいショートカットの作成は、アドオンを購入するまでできなくなります。
