# 標題

Automation Portal

# 一句話介紹

捷徑一次建立，隨處執行，日常重複的工作交給自動化。

# 說明

Automation Portal 是一款適用於 Windows 11 的系統匣應用程式，協助你把日常工作自動化。把經常重複的事情放進簡單的捷徑，一秒啟動，不必每天重複相同的點擊。

在視覺化編輯器中用簡單的步驟組出捷徑，也可以自己做一遍，讓錄製器幫你寫下步驟。你可以從圖庫中現成的捷徑開始，也可以用一句話描述想做的事，取得可以修改的草稿。

執行起來很快。按下 Win+Alt+空白鍵，輸入名稱或簡短別名，再按 Enter 即可。把常用的釘選起來，隨時在滑鼠游標處彈出。為捷徑設定專屬快速鍵，或把檔案拖曳到它的磁貼上，直接對這些檔案執行。

讓電腦主動替你開工。自動化可以在指定時間、接上充電器或耳機、開啟應用程式、連上 Wi-Fi、資料夾有變動、複製內容等時機執行捷徑。還能加上條件，例如星期幾、電池電量或是否有全螢幕應用程式。你可以選擇立即執行、先詢問，或只通知你。

一切由你掌控。信任一項自動化之前，可先用暫存資料夾中的範例檔案測試。執行過於頻繁的自動化會自動暫停，一個開關即可暫停全部。每次執行都會在執行記錄中逐步記載，「復原檔案變更」可以還原某次執行建立、移動、重新命名或取代過的檔案。

在任何應用程式中輸入 ;sig 這類短代碼，Automation Portal 就會換成你設定好的長文字。

AI 步驟是選用的。可以使用你電腦上的 Portal AI Host、Copilot+ 電腦上 Windows 內建的裝置端 AI，或你自己的 AI 帳戶來摘要、改寫、翻譯、描述圖片。只有當你執行的捷徑包含 AI 步驟時，才會使用 AI。

Automation Portal 已在 Microsoft Store 上架，適用於 x64 與 Arm64 的 Windows 11 電腦。

# 功能

- 在視覺化編輯器中用簡單步驟建立捷徑
- 用一句話描述工作，取得可編輯的草稿（需先設定 AI）
- Quick Run：按 Win+Alt+空白鍵，輸入名稱或別名，按 Enter
- 在任何應用程式中用 Ctrl+Alt+R 對選取的文字執行捷徑
- 系統匣圖示與快速面板，在滑鼠游標處顯示已釘選的捷徑
- 為每個捷徑設定專屬快速鍵，或把檔案拖曳到磁貼上執行
- 依時間、電源、應用程式、裝置、Wi-Fi、資料夾、剪貼簿等觸發的自動化
- 星期、時間、電源類型、電池電量、全螢幕應用程式等條件
- 立即執行、先詢問（執行或略過），或僅通知
- 在暫存資料夾中用範例檔案測試自動化
- 執行過於頻繁的自動化會自動暫停，一個開關暫停全部
- 文字片段：輸入短代碼，取得長文字
- 巨集錄製器：做一遍工作，再檢查產生的步驟
- 圖庫提供現成的捷徑，可新增並依需求修改
- 執行記錄：逐步結果、再次執行、從失敗的步驟開啟
- 復原檔案變更，還原被建立、移動、重新命名或取代的檔案
- 選用的 AI 步驟：摘要、改寫、翻譯、描述圖片
- 使用 Portal AI Host、Copilot+ 電腦上的 Windows AI 或你自己的 AI 帳戶
- 資料夾、釘選、圖示與色彩，以及保留 30 天的最近刪除
- ap 命令列與可分享的 .autoportal 檔案

# 免費版、附加元件與免費試用

Automation Portal 可免費下載與使用。免費版最多可有 5 個捷徑，並包含圖庫、Quick Run、文字片段、巨集錄製器與執行記錄。

選用的付費附加元件，在應用程式內透過 Microsoft Store 購買：
- Plus：最多 25 個捷徑。
- Pro：捷徑數量不限，並可建立新的自動化（排程與觸發程序）。只有 Pro 可以建立新的自動化。

免費 14 天 Pro 試用：在應用程式中選擇「開始 14 天免費試用」。不需要綁定信用卡。試用只在你按下按鈕時才開始，且每位 Windows 使用者僅限一次。試用結束後，你建立的內容不會被刪除：現有的捷徑與自動化會繼續執行，你仍可編輯、執行、開啟或關閉以及刪除它們。在購買附加元件之前，將無法建立新的自動化，也無法建立超出所用方案上限的新捷徑。
