# 标题

Automation Portal

# 一句话介绍

快捷方式一次创建，随处运行，日常重复的工作交给自动化。

# 说明

Automation Portal 是一款适用于 Windows 11 的托盘应用，帮你把日常工作自动化。把反复做的事情放进简单的快捷方式，一秒启动，不必每天重复同样的点击。

在可视化编辑器中用简单的步骤搭建快捷方式，也可以亲自做一遍，让录制器替你写出步骤。你可以从图库里现成的快捷方式开始，也可以用一句话描述想做的事，得到一份可以修改的草稿。

运行起来很快。按下 Win+Alt+空格，输入名称或简短别名，再按回车即可。把常用的固定下来，随时在鼠标指针处弹出。给快捷方式设置专属热键，或把文件拖到它的磁贴上，直接对这些文件运行。

让电脑主动替你开工。自动化可以在指定时间、接入充电器或耳机、打开应用、连上 Wi-Fi、文件夹发生变化、复制内容等时机运行快捷方式。还能加上条件，例如星期几、电池电量或是否有全屏应用。你可以选择立即运行、先询问，或只通知你。

一切由你掌控。信任一项自动化之前，可先用临时文件夹里的示例文件测试。运行过于频繁的自动化会被自动暂停，一个开关即可暂停全部。每次运行都会在运行历史中逐步记录，“撤销文件更改”可以恢复某次运行创建、移动、重命名或替换过的文件。

在任何应用中输入 ;sig 这样的短代码，Automation Portal 就会把它换成你预设的长文本。

AI 步骤是可选的。可以使用你电脑上的 Portal AI Host、Copilot+ 电脑上 Windows 自带的设备端 AI，或你自己的 AI 账户来总结、改写、翻译、描述图片。只有当你运行的快捷方式包含 AI 步骤时，才会使用 AI。

Automation Portal 已在 Microsoft Store 上架，适用于 x64 和 Arm64 的 Windows 11 电脑。

# 功能

- 在可视化编辑器中用简单步骤创建快捷方式
- 用一句话描述任务，得到可编辑的草稿（需先设置 AI）
- Quick Run：按 Win+Alt+空格，输入名称或别名，按回车
- 在任何应用中用 Ctrl+Alt+R 对选中的文本运行快捷方式
- 托盘图标和快速面板，在鼠标指针处显示已固定的快捷方式
- 为每个快捷方式设置专属热键，或把文件拖到磁贴上运行
- 按时间、电源、应用、设备、Wi-Fi、文件夹、剪贴板等触发的自动化
- 星期、时间、电源类型、电池电量、全屏应用等条件
- 立即运行、先询问（运行或跳过），或仅通知
- 在临时文件夹中用示例文件测试自动化
- 运行过于频繁的自动化会自动暂停，一个开关暂停全部
- 文本片段：输入短代码，得到长文本
- 宏录制器：做一遍任务，再检查生成的步骤
- 图库提供现成的快捷方式，可添加并按需修改
- 运行历史：逐步结果、再次运行、从失败的步骤打开
- 撤销文件更改，恢复被创建、移动、重命名或替换的文件
- 可选的 AI 步骤：总结、改写、翻译、描述图片
- 使用 Portal AI Host、Copilot+ 电脑上的 Windows AI 或你自己的 AI 账户
- 文件夹、固定、图标和颜色，以及保留 30 天的最近删除
- ap 命令行和可分享的 .autoportal 文件

Automation Portal 可免费下载和使用。免费版最多可有 5 个快捷方式，并包含图库、Quick Run、文本片段、宏录制器和运行历史。

可选的付费附加产品，在应用内通过 Microsoft Store 购买：
- Plus：最多 25 个快捷方式。
- Pro：快捷方式数量不限，并可创建新的自动化（计划和触发器）。只有 Pro 可以创建新的自动化。

免费 14 天 Pro 试用：在应用中选择“开始 14 天免费试用”。无需绑定银行卡。试用只在你按下按钮时才开始，且每个 Windows 用户仅限一次。试用结束后，你创建的内容不会被删除：现有的快捷方式和自动化继续运行，你仍可编辑、运行、开启或关闭以及删除它们。在购买附加产品之前，将无法创建新的自动化，也无法创建超出所用套餐上限的新快捷方式。
