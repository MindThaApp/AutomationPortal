# Title

Automation Portal

# Hook

Build shortcuts once, run them from anywhere, and let automations do the routine work.

# Description

Automation Portal is a tray app for everyday automation on Windows 11. Put the jobs you repeat into simple shortcuts, run them in a second, and stop doing the same clicks every day.

Build a shortcut from plain steps in a visual editor, or do the task once and let the recorder write the steps for you. Start from a ready-made shortcut in the Gallery, or describe what you want in a sentence and get a draft you can edit.

Run anything fast. Press Win+Alt+Space, type a name or a short alias, and press Enter. Pin your favourites and pop them up at the mouse pointer. Give a shortcut its own hotkey, or drag files onto its tile to run it on them.

Let your PC start things for you. Automations can run a shortcut at a time of day, when you plug in a charger or headphones, open an app, join a Wi-Fi network, change a folder, copy something and more. Add conditions such as weekday, battery level or a full-screen app. Choose whether it runs right away, asks you first, or just tells you.

You stay in control. Test an automation on sample files in a temporary folder before you trust it. An automation that runs too often is paused automatically, and one switch pauses them all. Every run is recorded step by step in Run History, and Undo file changes puts back files a run created, moved, renamed or replaced.

Type a short code such as ;sig in any app and Automation Portal swaps it for your longer text.

AI steps are optional. Summarise, rewrite, translate or describe pictures with Portal AI Host on your PC, Windows on-device AI on a Copilot+ PC, or your own AI account. AI is used only when a shortcut you run has an AI step.

Automation Portal is available from the Microsoft Store for Windows 11 on x64 and Arm64 PCs.

# Features

- Build shortcuts from simple steps in a visual editor
- Describe a task in a sentence and get an editable draft (needs an AI set up)
- Quick Run bar: press Win+Alt+Space, type a name or alias, press Enter
- Run a shortcut on selected text in any app with Ctrl+Alt+R
- Tray icon and a Quick Panel with your pinned shortcuts at the mouse pointer
- Give any shortcut its own hotkey, or drag files onto its tile to run it on them
- Automations that start by time, power, apps, devices, Wi-Fi, folders, clipboard and more
- Conditions such as weekday, time of day, power source, battery level and full-screen apps
- Run right away, ask first with Run and Skip, or just get told
- Test an automation on sample files in a temporary folder
- Runaway automations pause themselves, and one switch pauses them all
- Snippets: type a short code anywhere and get your longer text
- Macro recorder: do a task once and turn it into steps you can review
- Gallery of ready-made shortcuts to add and make your own
- Run History with step-by-step results, Run again and Open at failed step
- Undo file changes puts back files a run created, moved, renamed or replaced
- Optional AI steps: summarise, rewrite, translate and describe pictures
- Use Portal AI Host, Windows on-device AI on Copilot+ PCs, or your own AI account
- Folders, pinning, icons and colours, plus Recently deleted for 30 days
- ap command line and shareable .autoportal files

# Free version, add-ons and free trial

Automation Portal is free to download and use. The free version holds up to 5 shortcuts and includes the Gallery, Quick Run, snippets, the macro recorder and Run History.

Optional paid add-ons, bought in the Microsoft Store from inside the app:
- Plus: up to 25 shortcuts.
- Pro: as many shortcuts as you like, and the ability to make new automations (schedules and triggers). Only Pro can make new automations.

Free 14-day Pro trial: choose Start 14-day free trial in the app. No card is needed. The trial starts only when you press the button, and only once per Windows user. When it ends, nothing you made is removed: existing shortcuts and automations keep running and you can still edit, run, turn on or off, and delete them. Making new automations, and new shortcuts beyond your plan's limit, stops until you buy an add-on.
